# 验证集驱动的计划补充 v1（修订测试开放前）

登记于2026-10-06，主计划不覆盖，保留原始校验和。本补充依据 E00 的 train/val 诊断：B_weighted train macro AP约0.976、val约0.571，表现为显著泛化差距；扩大线性 C 范围未带来主要改善。没有读取任何新测试分数。

新增 E07：连通分量再加权。假设大型训练家族在已知标签损失中过度重复，改变训练权重可能帮助新分量泛化。每类仅在 known train 行计算分量大小，权重为 n_component^(-beta)，beta∈{0.5,1}，归一化均值为1；再以加权 P/N 计算 min(10,sqrt(Nw/Pw)) 正例权重。A/B/C、C∈{1,10,100}，种子20261006。标签和划分不变。对应路线 val AP提升≥0.005为成功标准，全部候选留档。

新增 E08：embedding 归一化敏感性。假设逐行 L2 或逐维标准化可能丢失/改变有用的幅度信息。固定变体：Bstd=训练均值/标准差变换后除sqrt(1280)（不做逐行L2）；Bcos=原始冻结embedding逐行L2（不做逐维标准化）；BstdL=Bstd拼接0.25倍train标准化的log1p(序列长度)；Cstd=[A,Bstd]/sqrt(2)，Ccos=[A,Bcos]/sqrt(2)。C∈{1,10,100,1000}、两种权重。所有统计只fit train；val AP相对对应B或C基线提升≥0.005为成功标准。

E06补充稳健性检查：按类在候选之间选择可能对稀有类的验证集过拟合。对该类选择规则另做5折验证分量检查：分量按固定seed的hash归入折，选择器仅用其余4折选候选，在留出折取该候选分数，拼成out-of-fold验证预测。每类若选择侧没有P/N则回退到预指定全局单模型。只有此交叉检查的macro AP比该全局单模型在同一验证集高至少0.002，按类选择器才有资格进入最终选择；其他候选保留为诊断但不入选。该检查只控制选择器的额外乐观性，基础模型及神经早停仍用过验证集，不能称为完全独立验证。

E06的按类选择池限制为各实验家族的验证优选，以及主实验C_weighted。各类别不直接从上百配置中挑最有利结果。全局两/三模型权重网格仍限250个组合。最终只选一套、只进行一次修订测试，纪律不变。
